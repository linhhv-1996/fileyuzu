不是每個打不開的影片都是 MOV 或 AVI 造成的。MKV、WebM、WMV 這幾種格式各自有自己的來源和麻煩之處：MKV 常見於下載的影集電影，WebM 多半來自網頁或瀏覽器，WMV 則是 Windows 早期留下來的產物。

這篇把三種格式各自的狀況講清楚，也一併整理少見的 FLV、MPEG 該怎麼處理。

## MKV 轉 MP4

### 為什麼會遇到 MKV？

MKV 是專門為了「裝更多東西」設計的格式，可以在同一個檔案裡塞進多條音軌（例如原音加中配）、多國字幕、章節標記。這也是為什麼透過網路取得的影集、電影檔案幾乎都是 MKV，發布者想在一個檔案裡滿足不同語言、不同字幕需求的觀眾。

問題是，MKV 的播放支援度遠不如 MP4。iPhone 內建的相簿或某些電視盒子的播放 App 常常直接不認得這個格式。

### 轉檔時最容易被忽略的坑：字幕會不見

MP4 對外掛字幕軌的支援並不完整，從 MKV 轉成 MP4 的時候，字幕通常會直接消失，音軌則大多能保留（如果原始檔案有多條音軌，轉檔時可以選擇要保留哪一條）。

如果你需要保留字幕，有兩個做法：

- **維持 MKV 格式**，只在支援 MKV 的播放器（例如 VLC）上看，不轉檔
- **把字幕燒進畫面**（hardcode），這樣字幕會變成畫面的一部分，轉成 MP4 之後也不會消失，缺點是之後沒辦法關閉字幕或切換語言

### 什麼情況適合把 MKV 轉成 MP4？

只是想在手機、平板、電視上順順地看，不特別在意多字幕多音軌的話，轉成 MP4（並保留你要的那一條音軌）是最省事的做法。要長期收藏、之後可能還要換語言看的內容，維持 MKV 反而比較好。

## WebM 轉 MP4

### 為什麼會遇到 WebM？

WebM 是 Google 開發的網頁專用格式，壓縮效率高、檔案小，很多網頁的背景影片、瀏覽器螢幕錄影工具、部分下載外掛存下來的影片都是這個格式。它是為了「在瀏覽器裡播放」設計的，不是為了「在手機相簿或剪輯軟體裡使用」設計的。

### WebM 常見的打不開狀況

Android 對 WebM 的支援還算完整，但 iPhone、iPad 原生對 WebM 的支援一直不穩定，用 iOS 內建相簿或某些 App 開啟常常失敗。要匯入 iMovie、PowerPoint 這類軟體做剪輯或簡報，也經常直接不支援。

轉成 MP4 之後，這些相容性問題基本上都會消失。

## WMV 轉 MP4

### 為什麼會遇到 WMV？

WMV 是微軟開發的格式，早期 Windows Movie Maker 匯出的影片、公司內部教學錄影、多年前用 Windows 相機軟體錄的內容，很多都是這個格式。它是 Windows 生態系裡的原生選項，離開這個生態系就開始出問題。

### WMV 常見的打不開狀況

Mac 和 iPhone 幾乎不支援 WMV，QuickTime 原生打不開。上傳到非微軟系的平台，也經常遇到處理失敗或畫質被壓縮得很誇張的狀況。如果你手上有多年前留下的 WMV 檔案想在現在的裝置上看，轉成 MP4 是幾乎唯一實用的做法。

## 少見但還是會遇到：FLV、MPEG

**FLV** 是早期 Flash 影片盛行時代的格式，很多老網站、舊版 YouTube 下載工具存下來的檔案是這個格式。現在瀏覽器已經全面棄用 Flash，FLV 檔案幾乎找不到原生支援的播放環境，轉成 MP4 是必要的一步。

**MPEG（.mpeg / .mpg）** 常見於較舊的數位相機、早期的 DVD 影像來源。檔案通常沒有經過現代編碼優化，體積偏大，轉成 MP4 之後除了相容性變好，檔案也會明顯縮小。

## 常見問題

### MKV 裡有兩條音軌（原音+中配），轉成 MP4 之後可以兩條都保留嗎？
可以選擇保留其中一條，也可以分別轉出兩個各自保留單一音軌的 MP4 檔案。目前主流的 MP4 播放環境對多音軌切換的支援不如 MKV 直覺，所以大多數人會選擇保留常用的那一條。

### WebM 轉成 MP4 之後，畫質會變差嗎？
不會，只要維持相近的輸出品質設定即可。WebM 用的 VP8/VP9 編碼跟 MP4 常用的 H.264 效率相近，轉檔主要是換包裝方式，不是重新壓縮到更低品質。

### 一次可以把不同格式（MKV、WebM、WMV 混在一起）丟進去轉嗎？
可以，工具支援批次處理，不同來源格式的檔案可以一起拖入，各自選好都轉成 MP4 即可，不需要分批操作。

### 轉出來的 MP4 在舊款電視或播放器上還是打不開？
確認轉檔時輸出編碼選的是 H.264 而不是 H.265，H.264 的相容性明顯更好，幾乎所有電視和播放器都支援。如果還是有問題，安裝 VLC 幾乎能播放所有格式，可以先用它確認檔案本身沒有損壞。

### FLV 或 MPEG 這種老格式，轉檔會失敗嗎？
一般不會，這些格式雖然舊，但編碼標準本身很成熟，轉換過程通常很順利。如果檔案本身有部分損壞（常見於早期下載不完整的 FLV），轉檔時可能只能處理到損壞點之前的畫面，這種情況需要找到完整的原始檔案才能解決。
