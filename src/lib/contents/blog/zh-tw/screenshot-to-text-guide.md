你想把一整個網頁、一長串 LINE 聊天記錄，或一份很長的文件畫面存成一張圖——這就是**長截圖**（捲動截圖）。但按下 `PrtSc` 或 `Shift + Cmd + 4`，抓到的永遠只有螢幕上看得到的那一段。

更麻煩的是，截完之後常常還有第二個需求：把截圖裡的文字複製出來。截圖是圖片，文字沒辦法直接選取。

這篇一次解決兩件事：**電腦長截圖怎麼截**（Windows / Mac，優先用不需要安裝的方法），以及**截圖怎麼轉成文字**。

---

## 電腦長截圖怎麼截？（Windows）

Windows 內建的截圖工具（剪取工具 / Snipping Tool）**不支援捲動截圖**——這就是為什麼你找不到這個功能。但如果你要截的是網頁，瀏覽器本身就內建了完整網頁截圖，完全不用安裝任何東西。

### 方法一：Edge 內建「網頁擷取」（最簡單）

Windows 都有 Edge，這是最快的方法：

1. 用 Edge 開啟要截的網頁
2. 按 `Ctrl + Shift + S`（或右上角「…」選單 →「網頁擷取」）
3. 選「**擷取整頁**」
4. 直接儲存成圖片

一整個網頁不管多長，一鍵存成一張完整截圖。

### 方法二：Firefox 內建截圖

1. 在網頁空白處按右鍵 → 選「**拍攝截圖**」
2. 點右上角「**儲存完整頁面**」
3. 下載 PNG

### 方法三：Chrome 開發者工具

Chrome 沒有介面上的按鈕，但功能藏在裡面：

1. 按 `F12` 開啟開發者工具
2. 按 `Ctrl + Shift + P` 開啟指令列
3. 輸入「screenshot」→ 選「**Capture full size screenshot**」
4. 自動下載完整網頁 PNG

### 方法四：ShareX（要截的不是網頁時）

如果要長截圖的對象不是網頁——例如 LINE 電腦版的聊天記錄、PDF 閱讀器、公司內部系統——瀏覽器內建功能就幫不上忙，需要用支援捲動截圖的工具。

**ShareX** 是免費開源的 Windows 截圖工具，支援「捲動擷取」：它會自動幫你捲動視窗、連續截圖、拼接成一張長圖。安裝後選「擷取」→「捲動擷取」，framing 對準目標視窗即可。

## Mac 長截圖的做法

**Safari 匯出整頁：** 選單列「檔案」→「匯出為 PDF」，整個網頁存成一份 PDF。要圖片的話，再用預覽程式把 PDF 頁面另存為 PNG。

**Chrome / Firefox：** 和 Windows 相同，Chrome 用開發者工具的 Capture full size screenshot，Firefox 用右鍵拍攝截圖。

**Shottr（免費）：** Mac 上的免費截圖工具，支援捲動截圖（Scrolling capture），可以截 App 視窗，不限於網頁。

**CleanShot X（付費）：** Mac 上功能最完整的截圖工具，長截圖一鍵完成，適合每天都要截圖的重度使用者。

## 長截圖的字太小？先做這一步

這是長截圖最常見、也最容易被忽略的問題:整頁縮成一張圖之後，每個字可能只剩幾個像素，之後不管是自己看還是要 OCR 轉文字，都很吃力。

**解法很簡單：截圖前先放大頁面。** Windows 按 `Ctrl + +`、Mac 按 `Cmd + +` 把網頁放大到 125–150%，再執行長截圖。輸出的圖片解析度會高很多，文字清清楚楚。

## 長截圖怎麼轉成文字？

截好長截圖之後，裡面的文字沒辦法直接複製——因為截圖只是像素，需要 OCR（光學文字辨識）把像素轉回文字。

把長截圖丟進 [uploadless.app 的圖片轉文字工具](/zh-tw/image-to-text)：支援大尺寸長截圖，辨識在瀏覽器本機執行，**圖片不會上傳到任何伺服器**——聊天記錄、公司系統畫面這類敏感內容也能放心處理。不用安裝、不用註冊。

長截圖 OCR 有幾個實用技巧：

**多欄版面先裁切。** 網頁長截圖通常有側欄、選單，OCR 容易把閱讀順序搞混。把需要的內容區域裁切出來個別辨識，結果乾淨很多。

**只需要某幾段的話，裁了再辨識。** 針對性裁切的準確率比跑整張長圖高。

**另一個思路：分段截圖 + 批次 OCR。** 與其截一張超長的圖，不如分段截成 3–5 張清楚的普通截圖，一次全部丟進工具批次辨識——工具支援多張圖片同時處理，結果分開輸出。直接用[圖片轉文字工具](/zh-tw/image-to-text)批次處理即可。

**聊天記錄辨識後要清理。** LINE 或 Messenger 的長截圖轉出來會包含時間戳、帳號名稱、表情符號，貼進文件前手動刪掉。

## 手機截圖轉文字

**iPhone（原況文字）：** 打開「照片」選擇截圖，長按文字區域直接選取、複製。長按沒反應的話，通常是文字太小——放大畫面重新截一次。另外，iPhone 在 Safari 截圖後選「整頁」可以存完整網頁，但存出來是 PDF 格式。

**Android（Google Lens）：** 打開相簿或 Google Photos，點 Lens 或文字辨識功能，選取並複製文字。大部分 Android 品牌也內建捲動截圖：截圖後點「捲動擷取」或「擴大截圖」按鈕，就能往下延伸截更長的畫面。

手機上辨識不了、或需要批次處理的時候，一樣可以用瀏覽器開 [圖片轉文字工具](/zh-tw/image-to-text)，手機瀏覽器直接能跑。

## 哪些截圖最容易辨識成功？

截圖品質直接決定 OCR 效果：

**文字夠大。** 長截圖、整頁截圖最常見的問題就是字被縮太小。截圖前先放大（`Ctrl + +`），效果差很多。

**用原始截圖，不要用轉傳版。** 圖片每經過 LINE 或 Messenger 轉傳一次就被壓縮一次，傳幾手之後文字邊緣糊掉，辨識率大降。

**背景乾淨、對比足夠。** 黑字白底最好認。文字壓在照片背景、漸層底圖上，或顏色太淡、有浮水印遮蓋，準確率都會下降。

**版面單純。** 單欄文字比表格、多欄混排容易辨識。複雜版面就裁切分段處理。

**沒有遮擋。** 浮動按鈕、彈窗、貼圖蓋住文字會漏字，截圖前先關掉。

## 常見使用情境

**整理聊天記錄。** 客服對話、工作討論要整理成文件，聊天 App 又不方便大量複製——長截圖 + OCR 是最快的路徑。

**擷取不能複製的文字。** 有些網頁和 App 鎖住文字選取，或文字本身就是圖片：訂單畫面、線上課程、圖片式公告、系統錯誤訊息。截圖轉文字是最實用的替代方案。錯誤碼這類內容辨識後要核對大小寫和符號。

**課程與簡報筆記。** 投影片截圖轉成文字後可以搜尋、翻譯、貼進筆記軟體。簡報字通常偏小，記得放大再截。

## 截圖轉文字後的整理重點

OCR 輸出是初稿，貼去正式用途前快速過一遍：

- **換行**：截圖版面造成的斷行會被保留，同段文字要手動接回去
- **數字與英文**：日期、金額、電話、網址、錯誤碼最容易錯一兩個字元
- **繁體相近字**：「己/已/巳」、「土/士」、「末/未」這類筆畫相近的字，低解析度時容易混淆
- **多餘元素**：時間戳、帳號名、按鈕文字，轉完刪掉

## 常見問題

### 電腦可以長截圖嗎？Windows 內建有這個功能嗎？

Windows 內建的剪取工具不支援捲動截圖。但如果對象是網頁，Edge（`Ctrl + Shift + S` → 擷取整頁）、Firefox（右鍵 → 拍攝截圖 → 完整頁面）和 Chrome（開發者工具）都內建完整網頁截圖，不用安裝任何軟體。非網頁的視窗要用 ShareX 這類支援捲動擷取的免費工具。

### LINE 電腦版的聊天記錄怎麼長截圖？

LINE 電腦版不是網頁，瀏覽器內建功能用不上。Windows 用 ShareX 的捲動擷取對準聊天視窗，Mac 用 Shottr 的 Scrolling capture。截完如果要把對話內容轉成文字，丟進 [圖片轉文字工具](/zh-tw/image-to-text) 辨識，本機處理不上傳，聊天內容不會外流。

### 電腦長截圖怎麼擷取裡面的文字？

把長截圖存成 PNG，丟進 OCR 工具辨識。多欄版面（例如網頁有側欄）建議先裁切需要的區域再辨識，閱讀順序比較不會亂。字太小的話先放大畫面（`Ctrl + +`）再重截，準確率差很多。

### 長截圖轉文字，字太小辨識不出來怎麼辦？

回到原始畫面，放大到 125–150% 再截一次。放大已經截好的圖片沒有用——放大是像素插值，不會增加真實細節。

### 截圖中的繁體中文可以辨識嗎？

可以，但繁體字筆畫多，圖片太小或模糊時容易出錯，尤其是筆畫相近的字。辨識後建議校對一遍，重點看日期、金額、姓名。

### 模糊截圖可以 OCR 嗎？

可以試，但效果通常不好。文字邊緣已經糊在一起的話，最好的做法是回到原始畫面重新截圖。

### 截圖轉文字會保留排版嗎？

不一定。OCR 主要目標是擷取文字，表格、多欄、對話框這類格式通常需要手動整理。

電腦長截圖：網頁用瀏覽器內建（Edge 最快），非網頁視窗用 ShareX / Shottr。截之前先放大字體，這一步決定了截圖能不能看、能不能辨識。
