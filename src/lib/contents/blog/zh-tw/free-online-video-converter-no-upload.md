## 影片格式是什麼？為什麼同一個影片要轉成不同格式？

影片格式（副檔名）是一個容器，決定影片怎麼被打包和儲存，也決定哪些裝置或軟體能讀取它。

同一段影片轉成不同格式，不是在改變畫面內容，而是在改變打包方式。就像同一本書可以出精裝版、平裝版、電子版 — 內容一樣，但載體不同，適合不同的閱讀情境。

轉錯格式最常見的後果：對方打不開、播放器報錯、上傳平台失敗、剪輯軟體匯入異常。

## 五種主流格式的差別

### MP4（.mp4）

**最通用的格式。** 幾乎所有裝置、平台、軟體都支援：Windows、Mac、iPhone、Android、YouTube、Instagram、LINE、剪輯軟體。

檔案相對小、畫質好、相容性最高。如果你不確定要用哪個格式，選 MP4 通常不會錯。

唯一的弱點是多音軌和字幕的支援比 MKV 差，但日常用途幾乎遇不到這個問題。

### MOV（.mov）

**Apple 的原生格式。** iPhone 和 Mac 拍的影片預設都是 MOV，在 Apple 生態系裡播放完全沒問題。

但傳給 Windows 用戶、上傳到非 Apple 平台，有時候對方打不開，或需要額外安裝播放器。iCloud 備份、Final Cut Pro 剪輯用 MOV 很合適，跨平台分享就換成 MP4。手上的影片如果是這個情況，可以直接看 [MOV 轉 MP4 完整教學](/zh-tw/blog/mov-to-mp4-free-no-upload)。

### AVI（.avi）

**Windows 早期格式，相容性靠得住但檔案偏大。** 優點是舊版 Windows 軟體支援度高，缺點是同樣畫質下檔案通常比 MP4 大很多，也不適合網路串流。

主要用途是跟使用老舊 Windows 環境的對象交換檔案，或是特定剪輯軟體指定需要 AVI 輸入時。一般日常分享不建議用。舊攝影機或舊電腦錄的 AVI 檔案，可以參考 [AVI 轉 MP4 完整教學](/zh-tw/blog/avi-to-mp4-free-no-upload)。

### MKV（.mkv）

**保留最多資訊的格式。** MKV 最大的優點是可以同時包多條音軌、多語言字幕、章節標記，全部塞在同一個檔案裡。外掛字幕的電影、雙語版本、多音軌素材，通常都是 MKV。

播放需要支援 MKV 的播放器（VLC 沒問題，Windows Media Player 舊版不支援）。不適合直接上傳社群平台，但用來長期保存高品質影片或剪輯素材很合適。

### WebM（.webm）

**專門給網頁設計的格式。** WebM 是 Google 開發的開放格式，壓縮效率高、檔案小、瀏覽器原生支援，專門用在網頁嵌入影片。

開發者用 `<video>` 標籤嵌入網頁背景影片，或是 Web App 裡的影片元素，WebM 是常見選擇。如果你不是在做網頁開發，這個格式日常用不到。MKV、WebM 或是從網路下載的影片打不開，可以看 [MKV、WebM、WMV 轉 MP4 完整指南](/zh-tw/blog/video-formats-to-mp4-free-no-upload)。

## 依使用場景選格式

不同情況適合的格式不太一樣，直接對照：

- **傳給朋友、家人** → MP4，任何裝置都能打開
- **上傳 YouTube、Instagram、TikTok** → MP4，平台相容性最好
- **用 LINE 或 Messenger 傳送** → MP4，壓縮後畫質損失最小
- **iPhone 影片傳到 Windows** → MP4，MOV 在 Windows 常打不開
- **Mac、Final Cut Pro 剪輯** → MOV，Apple 生態系原生支援
- **傳給用舊版 Windows 軟體的人** → AVI，舊系統相容性最高
- **保存附字幕的影片或電影** → MKV，多軌道、多字幕支援
- **長期備份高品質原始素材** → MKV，無損儲存更多資訊
- **網頁嵌入影片** → WebM，瀏覽器原生、檔案小

## 轉檔會影響畫質嗎？

取決於設定，不取決於格式本身。

大多數格式之間的轉換，如果保持相同的編碼品質設定，畫質幾乎看不出差異。常見的誤解是「MOV 一定比 MP4 畫質好」，實際上 MOV 和 MP4 都可以用相同的 H.264 或 H.265 編碼，畫質完全一樣。

真正影響畫質的是轉換時的壓縮程度。轉成 MP4 時如果把碼率壓得很低，畫質才會下降。格式本身不是問題，設定才是。

## 轉檔時要注意：不同格式的編碼相容性

格式（容器）和編碼（codec）是兩回事。MP4 裡可以放 H.264，也可以放 H.265；MKV 裡可以放幾乎任何編碼。

實際使用最常遇到的問題：

**iPhone 錄的 H.265 影片轉 MP4** — 如果對方的裝置不支援 H.265 解碼，打開會異常。轉檔時選擇輸出 H.264 編碼的 MP4，相容性更好。

**MKV 字幕轉 MP4 會消失** — MP4 對外掛字幕的支援不完整，從 MKV 轉 MP4 時，字幕軌通常會被丟掉。如果需要保留字幕，維持 MKV 或先把字幕燒進影片（hardcode）再轉。

**AVI 不支援 H.264 以上的新編碼** — AVI 是舊容器格式，遇到新編碼的來源影片轉換時偶爾會出問題。

### 轉出來的 MP4 用 LINE 或 Messenger 傳，對方收到會很大包嗎？
轉檔時可以順便調整輸出品質和解析度，把檔案壓到適合即時通訊傳送的大小，不需要另外用壓縮工具處理一次。

### MP4 以外，有沒有更適合長期保存的格式？
如果影片是要長期典藏、之後可能還要重新剪輯，MKV 會比 MP4 更適合，因為它能保留多音軌和字幕、對畫質也沒有額外壓縮限制。日常分享或上傳社群平台，MP4 還是首選。

### 轉檔過程卡住不動或失敗怎麼辦？
通常是檔案本身有些微損壞，或瀏覽器分頁在背景被系統回收記憶體。重新整理頁面、換一個分頁單獨處理該檔案，或先關掉其他佔用記憶體的分頁，多半可以解決。
