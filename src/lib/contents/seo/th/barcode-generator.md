## สร้างบาร์โค้ดออนไลน์ บนเบราว์เซอร์ของคุณ

โปรแกรมสร้างบาร์โค้ดฟรีนี้ช่วยให้คุณสร้างรูปภาพบาร์โค้ดที่สแกนได้โดยตรงบนเบราว์เซอร์ของคุณ เพียงแค่พิมพ์รหัส อัปโหลดสเปรดชีต หรือสร้างชุดตัวเลขแบบรันลำดับต่อเนื่อง — จากนั้นดาวน์โหลดบาร์โค้ดของคุณเป็นไฟล์ PNG หรือ SVG

ทุกอย่างทำงานแบบออฟไลน์บนอุปกรณ์ของคุณโดยตรง ข้อมูล SKU หมายเลขซีเรียล รหัสทรัพย์สิน และข้อมูลผลิตภัณฑ์ของคุณจะไม่ถูกอัปโหลดไปยังเซิร์ฟเวอร์ สำหรับการสร้างบาร์โค้ด เรื่องนี้สำคัญกว่าที่คุณคิด: ข้อมูลที่คุณเข้ารหัสส่วนใหญ่มักเป็นข้อมูลภายในของธุรกิจ — เช่น รหัสสินค้าที่ยังไม่เปิดตัว ตำแหน่งที่จัดเก็บในคลังสินค้า รายการสินค้าคงคลังของลูกค้า — และไม่มีเหตุผลใดที่ข้อมูลเหล่านั้นจะต้องไปอยู่บนเซิร์ฟเวอร์ของคนอื่นเพียงเพื่อสร้างรูปภาพ

ไม่ต้องสมัครสมาชิก ไม่มีลายน้ำ ไม่ต้องติดตั้ง

---

## 3 วิธีในการสร้างบาร์โค้ด

เครื่องมือนี้มี 3 โหมดการทำงาน ขึ้นอยู่กับจำนวนบาร์โค้ดที่คุณต้องการและแหล่งที่มาของข้อมูลคุณ

### โหมดกำหนดเอง: สร้างบาร์โค้ดทีละรายการ

พิมพ์หรือวางข้อมูล เลือกประเภทบาร์โค้ด แล้วบาร์โค้ดจะปรากฏขึ้นทันที สามารถเพิ่มข้อความที่อ่านได้ไว้ด้านล่าง (ใส่หรือไม่ใส่ก็ได้) จากนั้นดาวน์โหลดเป็นไฟล์ PNG หรือ SVG

โหมดกำหนดเองเป็นตัวเลือกที่เร็วที่สุดเมื่อคุณต้องการบาร์โค้ดเพียงอันเดียว — เช่น แท็กทรัพย์สินแบบด่วน ป้ายทดสอบ รหัสผลิตภัณฑ์ 1 รายการ หรือคิวอาร์โค้ด (QR code) สำหรับลิงก์

### โหมดอัปโหลด: สร้างบาร์โค้ดจำนวนมากจาก Excel หรือ CSV

หากรหัสของคุณอยู่ในสเปรดชีตอยู่แล้ว ไม่จำเป็นต้องพิมพ์ใหม่ เพียงอัปโหลดไฟล์ Excel หรือ CSV แล้วเครื่องมือจะสร้างบาร์โค้ดทั้งหมดพร้อมกันในคราวเดียว

รูปแบบไฟล์นั้นเรียบง่ายมาก:

| คอลัมน์ | วัตถุประสงค์ | ตัวอย่าง |
| :--- | :--- | :--- |
| คอลัมน์ A | ค่าบาร์โค้ด | `SKU-001` |
| คอลัมน์ B | ป้ายกำกับ (ไม่บังคับ) | `Blue T-Shirt - Medium` |

คอลัมน์ A คือสิ่งที่เครื่องสแกนจะอ่าน คอลัมน์ B คือข้อความที่พิมพ์ใต้บาร์โค้ดเพื่อให้มนุษย์สามารถระบุสินค้าได้เช่นกัน สเปรดชีตของคุณจะถูกประมวลผลบนเบราว์เซอร์ของคุณโดยตรง — ไฟล์จะไม่ถูกส่งออกจากอุปกรณ์ของคุณ

โหมดนี้สร้างขึ้นสำหรับรายการสินค้าคงคลัง แคตตาล็อกผลิตภัณฑ์ ทะเบียนทรัพย์สิน และรายชื่อป้ายชื่อสำหรับงานอีเวนต์

### โหมดรันลำดับ: สร้างชุดตัวเลขต่อเนื่องในไม่กี่วินาที

ต้องการสร้างรหัสตั้งแต่ `INV-2026-001` ถึง `INV-2026-500` ใช่ไหม? โหมดรันลำดับจะสร้างชุดตัวเลขที่เรียงตามลำดับให้โดยอัตโนมัติ เพียงกำหนดคำนำหน้า ตัวเลขเริ่มต้น และจำนวนที่ต้องการ — เครื่องมือจะจัดการส่วนที่เหลือทั้งหมดโดยที่คุณไม่ต้องแตะสเปรดชีตเลย

นี่คือวิธีที่รวดเร็วที่สุดในการสร้าง:

* ป้ายติดกล่องเก็บของและถังขยะ
* ป้ายระบุทรัพย์สินแบบมีหมายเลข
* หมายเลขตั๋วหรือป้ายชื่อ
* หมายเลขคำสั่งซื้อและหมายเลขล็อต
* รหัสชั้นวางและรหัสตำแหน่งที่ตั้ง

เครื่องมือสร้างบาร์โค้ดส่วนใหญ่มักบังคับให้คุณสร้างลำดับใน Excel ก่อน แต่ที่นี่ ระบบรันหมายเลขถูกติดตั้งมาให้พร้อมใช้งาน

---

## ประเภทบาร์โค้ดที่รองรับ

โปรแกรมสร้างบาร์โค้ดนี้รองรับรูปแบบบาร์โค้ด 1D และ 2D ที่ใช้กันอย่างแพร่หลายที่สุด:

| ประเภทบาร์โค้ด | เหมาะสำหรับ |
| :----------- | :-------------------------------------------------------------- |
| Code 128 | รหัส SKU, สินค้าคงคลัง, ป้ายระบุทรัพย์สิน, หมายเลขซีเรียล, ป้ายกำกับภายใน |
| UPC-A | สินค้าปลีกในสหรัฐอเมริกาและแคนาดา (12 หลัก) |
| EAN-13 | สินค้าปลีกที่ขายในระดับสากล (13 หลัก) |
| JAN | สินค้าปลีกในประเทศญี่ปุ่น (EAN-13 ที่มีรหัสคำนำหน้าของญี่ปุ่น) |
| EAN-8 | สินค้าปลีกขนาดเล็กที่มีพื้นที่ติดป้ายจำกัด (8 หลัก) |
| ITF-14 | กล่องจัดส่งและบรรจุภัณฑ์หุ้มห่อภายนอก (14 หลัก) |
| QR Code | URL, ข้อความ, ข้อมูล Wi-Fi, ข้อมูลการติดต่อ, การสแกนผ่านมือถือ |

### คุณควรเลือกบาร์โค้ดประเภทใด?

**สำหรับการใช้งานภายใน** — สินค้าคงคลัง, ถังในโกดัง, การติดตามทรัพย์สิน, ป้ายพนักงาน — แนะนำให้ใช้ **Code 128** เนื่องจากสามารถเข้ารหัสตัวอักษร ตัวเลข และสัญลักษณ์ทั่วไปได้ ดังนั้นรหัสอย่าง `ASSET-LAPTOP-024` จะใช้งานได้โดยไม่มีข้อจำกัด

**สำหรับสินค้าปลีก** รูปแบบจะขึ้นอยู่กับสถานที่ที่คุณขาย: **UPC-A** สำหรับสหรัฐอเมริกาและแคนาดา, **EAN-13** สำหรับตลาดสากล, **JAN** สำหรับประเทศญี่ปุ่น, **EAN-8** สำหรับบรรจุภัณฑ์ที่มีขนาดเล็กมาก โปรดทราบว่ารูปแบบเหล่านี้จำเป็นต้องใช้หมายเลขผลิตภัณฑ์ที่ถูกต้อง

**สำหรับกล่องจัดส่งและลังบรรจุสินค้า** แนะนำให้ใช้ **ITF-14** โดยจะเข้ารหัส GTIN 14 หลัก และออกแบบมาสำหรับกล่องลูกฟูก ซึ่งบาร์โค้ดขายปลีกมาตรฐานมักจะพิมพ์ออกมาได้ไม่คมชัด

**สำหรับสิ่งใดก็ตามที่ต้องสแกนด้วยโทรศัพท์** — ลิงก์, เมนู, คำแนะนำ, การเช็คอิน — แนะนำให้ใช้ **QR Code**

---

## ดาวน์โหลดเป็นไฟล์ PNG หรือ SVG

บาร์โค้ดทุกอันสามารถส่งออกได้ 2 รูปแบบ:

* **PNG** — รูปภาพพร้อมใช้งานสำหรับเอกสาร Word, แม่แบบป้ายสติกเกอร์ Avery, ซอฟต์แวร์เครื่องพิมพ์ฉลากความร้อน, สเปรดชีต และการพิมพ์แบบด่วน
* **SVG** — ไฟล์เวกเตอร์ที่ขยายขนาดได้โดยไม่เบลอ เหมาะสำหรับบรรจุภัณฑ์ผลิตภัณฑ์, เลย์เอาต์ใน Illustrator หรือ Figma และการส่งมอบงานให้นักออกแบบ

กฎง่ายๆ คือ: เลือก PNG สำหรับป้ายสติกเกอร์และเอกสารสำนักงาน และเลือก SVG สำหรับบรรจุภัณฑ์และงานออกแบบ

---

## การพิมพ์บาร์โค้ดของคุณ

บาร์โค้ดที่ดูสมบูรณ์แบบบนหน้าจอ อาจไม่สามารถสแกนได้หากพิมพ์ออกมาเล็กเกินไป ถูกยืดออก หรือถูกตัดขอบ ก่อนที่จะพิมพ์แบบเต็มจำนวน ควรทำตามนี้:

1. ล็อกอัตราส่วนภาพไว้เสมอเมื่อปรับขนาด — ห้ามยืดความกว้างหรือความสูงแยกกันเด็ดขาด
2. รักษาระยะขอบที่ปลอดภัย (พื้นที่ว่างรอบๆ แถบบาร์โค้ด)
3. พิมพ์แถบสีดำบนพื้นหลังสีขาวด้าน เพื่อให้ได้คอนทราสต์ที่ชัดเจนที่สุด
4. พิมพ์ตัวอย่างหนึ่งชิ้นและทดสอบสแกนก่อนที่จะพิมพ์บาร์โค้ดทั้งหมด

---

## สำคัญ: รูปภาพบาร์โค้ด กับ หมายเลขผลิตภัณฑ์อย่างเป็นทางการ

เครื่องมือนี้ทำหน้าที่สร้าง **รูปภาพ** บาร์โค้ดเท่านั้น แต่ไม่ได้ออกหมายเลขผลิตภัณฑ์ขายปลีกอย่างเป็นทางการให้คุณ

สำหรับป้ายกำกับภายใน — รหัส SKU, ป้ายระบุทรัพย์สิน, รหัสคลังสินค้า — คุณสามารถสร้างข้อมูลใดๆ ก็ได้ตามที่คุณต้องการแล้วเข้ารหัสด้วย Code 128 ซึ่งนั่นคือจุดประสงค์หลักของบาร์โค้ดภายใน

แต่หากคุณกำลังขายสินค้าผ่านร้านค้าปลีกหรือแพลตฟอร์มมาร์เก็ตเพลส หมายเลข UPC, EAN หรือ JAN ของคุณจะต้องเป็นรหัสระบุตัวตนอย่างเป็นทางการที่ลงทะเบียนกับธุรกิจของคุณแล้ว การสร้างรูปภาพจากหมายเลขที่ยังไม่ได้ลงทะเบียน ก็จะยังคงเป็นหมายเลขที่ยังไม่ได้ลงทะเบียนอยู่ดี

## คำถามที่พบบ่อย

### โปรแกรมสร้างบาร์โค้ดนี้ฟรีจริงๆ หรือไม่?

ใช่ ทั้งสามโหมดการทำงาน ได้แก่ โหมดกำหนดเอง อัปโหลดไฟล์ และโหมดรันลำดับ — เปิดให้ใช้งานฟรี โดยไม่ต้องสมัครสมาชิก ไม่มีลายน้ำ และไม่จำกัดจำนวนการดาวน์โหลด

### ข้อมูลของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่?

ไม่ บาร์โค้ดทั้งหมดจะถูกสร้างขึ้นแบบออฟไลน์บนเบราว์เซอร์ของคุณ ไฟล์ Excel และ CSV ที่อัปโหลดก็จะถูกประมวลผลบนอุปกรณ์ของคุณ และไม่มีการส่งออกไปที่ใด

### ฉันสามารถสร้างบาร์โค้ดหลายอันพร้อมกันได้หรือไม่?

ได้ คุณสามารถใช้โหมดอัปโหลดเพื่อสร้างบาร์โค้ดจำนวนมากจากไฟล์ Excel หรือ CSV หรือใช้โหมดรันลำดับเพื่อสร้างชุดตัวเลขที่เรียงตามลำดับอัตโนมัติ

### ฉันสามารถใช้เครื่องมือนี้เพื่อสร้างบาร์โค้ด UPC หรือ EAN สำหรับสินค้าของฉันได้หรือไม่?

ได้ หากคุณมีหมายเลข UPC, EAN หรือ JAN ที่ถูกต้องอยู่แล้ว เครื่องมือนี้จะช่วยสร้างรูปภาพที่นำไปสแกนได้ แต่ไม่ได้ทำหน้าที่ลงทะเบียนรหัสระบุผลิตภัณฑ์อย่างเป็นทางการ หากต้องการนำไปขายปลีก คุณจะต้องขอหมายเลขอย่างเป็นทางการก่อน

### ฉันควรใช้บาร์โค้ดประเภทใดสำหรับป้ายติดสินค้าคงคลัง?

Code 128 เนื่องจากรองรับทั้งตัวอักษร ตัวเลข และสัญลักษณ์ ซึ่งถือเป็นรูปแบบที่ยืดหยุ่นที่สุดสำหรับรหัส SKU, หมายเลขซีเรียล และป้ายระบุทรัพย์สิน

### ฉันควรดาวน์โหลดเป็น PNG หรือ SVG?

PNG เหมาะสำหรับแม่แบบป้ายสติกเกอร์ เอกสารสำนักงาน และการพิมพ์ผ่านเครื่องพิมพ์ความร้อน ส่วน SVG เหมาะสำหรับอาร์ตเวิร์กบรรจุภัณฑ์และซอฟต์แวร์การออกแบบ เนื่องจากสามารถขยายขนาดได้โดยที่ภาพไม่เบลอ

### บาร์โค้ดจะสแกนได้อย่างถูกต้องเมื่อพิมพ์ออกมาหรือไม่?

ได้ ตราบใดที่คุณพิมพ์ออกมาอย่างคมชัด: ขนาดถูกต้อง, ล็อกอัตราส่วนภาพไว้, มีคอนทราสต์ที่ชัดเจน และรักษาระยะขอบที่ปลอดภัยไว้ แนะนำให้ทดสอบสแกนตัวอย่างก่อนพิมพ์จริงเสมอ
