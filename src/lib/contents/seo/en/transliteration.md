## How to Type: Choose a Language, Then Type Phonetically

### Step 1: Choose Your Language

Select your target language from the dropdown before you start typing. This tells the tool which script and phonetic rules to apply, so `zh` maps to the right sound in Russian and to a different one in Arabic.

### Step 2: Type Phonetically and Pick from the Suggestions

Type the word the way it sounds using English letters — for example, `namaste` for Hindi or `spasibo` for Russian. As you type, a suggestion list appears showing the most likely native-script matches, the same way Google Input Tools works. Click the correct suggestion, and it's inserted in place of what you typed. If the first match isn't quite right, keep typing — the list narrows as you add more letters.

This suggestion-based approach exists because phonetic spelling is rarely one-to-one: the same sequence of English letters can map to more than one native word, especially in languages with sounds that don't have a clean Latin equivalent. Picking from the list, instead of hoping the first guess is correct, is what keeps the output accurate.

## Important: Transliteration Is Not Translation

This tool converts the *sound* of a word into a different script — it does not translate meaning between languages. You still need to know the word you want to write in your target language; the tool's job is to render it correctly in native script instead of you typing or hunting for the characters yourself. If you type an English word that has no direct phonetic equivalent, the suggestion list won't have a meaningful match — that's expected, and it's a sign you need the translated word, not the transliterated one.

## Frequently Asked Questions

### Is this transliteration tool really free?
Yes. Typing, language selection, suggestions, and copying your result are all free, with no sign-up, watermark, or usage limit.

### Is my typed text uploaded to a server?
No. Conversion happens entirely in your browser. Nothing you type is transmitted to or stored on any server.

### Why do I see a list of suggestions instead of one direct result?
Phonetic spelling can map to more than one native word, especially for sounds that don't have a single clean Latin equivalent. The suggestion list lets you pick the exact match instead of settling for a guess.

### Is transliteration the same as translation?
No. Translation changes the meaning of a word between languages. Transliteration keeps the same word and language but changes the script — you already know the word; the tool renders it in the correct native script.

### Which languages does this support?
Hindi, Urdu, Tamil, Punjabi, Gujarati, Marathi, Bengali, Arabic, Russian, and Sinhala — select your target language from the dropdown before you start typing.

### Do I need to install a keyboard layout or IME to use this?
No. You keep typing on your existing English keyboard. Language selection and phonetic suggestions handle the rest, so there's nothing to install or configure at the OS level.

### Does this work on mobile as well as desktop?
Yes. Since it runs entirely in your browser, it works the same way on a phone or tablet browser as it does on desktop, with no app to install on either.
