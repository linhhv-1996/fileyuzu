## 이미지 텍스트 추출이란?

**이미지 텍스트 추출**은 사진이나 스크린샷 안에 있는 글자를 직접 선택하고, 복사하고, 편집할 수 있는 텍스트로 바꿔주는 기능입니다. "이미지 텍스트 변환", "사진 텍스트 추출", "이미지 글자 추출"이라고도 부르지만 모두 같은 작업을 가리킵니다. OCR(광학 문자 인식) 기술을 사용해 이미지 속 픽셀 패턴을 하나하나 글자로 인식하는 방식입니다.

위 도구는 이 작업을 브라우저에서 무료로, 설치 없이, 횟수 제한 없이 처리합니다. JPG, PNG, JPEG 등 일반적인 이미지 파일을 올리기만 하면 되고, 워터마크도 붙지 않습니다. 회원가입도 필요 없습니다.

모든 처리는 사용자의 브라우저 안에서 WebAssembly로 실행되며, 이미지 파일이 외부 서버로 전송되지 않습니다.

---

## 컴퓨터가 이미지 속 글자를 바로 못 읽는 이유

이미지 파일은 색상 값이 채워진 픽셀의 격자일 뿐입니다. 사람 눈에는 글자가 또렷하게 보여도, 파일 내부에는 "이것은 '가'라는 글자다"라는 정보가 전혀 저장되어 있지 않습니다. 그래서 이미지 안의 문장을 마우스로 드래그해 복사하는 것이 불가능합니다.

OCR은 이 문제를 해결하기 위한 기술입니다. 이미지에서 글자로 보이는 영역을 찾아내고(텍스트 감지), 각 영역의 획과 형태를 분석해 어떤 문자인지 판별한 뒤(문자 인식), 인식된 문자를 순서대로 이어 실제 복사 가능한 텍스트로 재구성합니다. 인쇄체는 폰트가 일정해 상대적으로 인식이 쉽지만, 한글처럼 초성·중성·종성이 조합되는 문자 체계이거나 손글씨처럼 형태가 사람마다 다른 경우에는 훨씬 정교한 인식 과정이 필요합니다.

## 이럴 때 이미지 텍스트 추출이 필요합니다

사진이나 캡처 속에 필요한 정보가 갇혀 있는 상황은 생각보다 다양합니다.

**스크린샷 속 대화, 오류 메시지, 슬라이드**
카카오톡 대화 캡처, 웹페이지 오류 메시지, 온라인 강의 슬라이드처럼 화면을 캡처한 이미지에서 문장을 그대로 복사하고 싶을 때가 많습니다. 스크린샷은 일반 사진보다 글자가 선명해 OCR 결과도 좋은 편입니다. 캡처 이미지를 다룰 때 알아두면 좋은 팁은 [스크린샷 텍스트 추출 가이드](/ko/blog/screenshot-text-extraction)에 정리해두었습니다.

**손글씨 노트, 회의 메모, 화이트보드**
강의 필기, 회의실 화이트보드, 수첩에 눌러쓴 메모도 사진으로 찍어 텍스트로 바꿀 수 있습니다. 손글씨는 인쇄체보다 인식이 까다로워 별도의 요령이 필요한데, 자세한 내용은 [손글씨 텍스트 변환 가이드](/ko/blog/free-korean-ocr-handwriting)를 참고하세요.

**외국어 이미지, 여행 중 찍은 안내문**
일본어 상품 설명, 영어 매뉴얼, 러시아어나 태국어로 된 안내문처럼 외국어가 이미지 안에 있으면 번역기에 바로 붙여넣을 수가 없습니다. 이럴 때는 먼저 OCR로 텍스트를 추출한 뒤 번역기에 넣는 방식이 훨씬 빠릅니다. 언어별 인식 팁은 [다국어 OCR 가이드](/ko/blog/multilingual-ocr-image-text)에서 확인할 수 있습니다.

**스캔 문서, 영수증, 인쇄물 사진**
계약서를 스캔한 이미지, 영수증 사진, 책이나 문서를 촬영한 사진에서 특정 문장이나 숫자만 빠르게 옮겨 적어야 할 때도 유용합니다. 타이핑으로 옮기다 생기는 오타 위험도 줄일 수 있습니다.

## UploadLess로 이미지에서 텍스트 추출하는 방법

1. 위 도구에 텍스트를 추출할 이미지를 업로드하거나, 클립보드에 복사된 스크린샷을 바로 붙여넣습니다.
2. 이미지 속 언어에 맞는 옵션을 선택합니다.
3. OCR이 실행되는 동안 잠시 기다립니다. (처음 실행 시 모델을 브라우저에 불러오는 시간이 조금 걸릴 수 있습니다.)
4. 인식된 텍스트를 확인하고, 전체 또는 필요한 부분만 복사해 원하는 곳에 붙여넣습니다.

## 이미지를 서버에 올리지 않는 이유

온라인 OCR 사이트 대부분은 사용자가 올린 이미지를 서버로 전송해 처리한 뒤 결과를 돌려주는 방식입니다. 하지만 이미지 안에는 생각보다 민감한 정보가 많이 들어 있습니다. 메신저 대화 캡처, 계좌번호가 찍힌 영수증, 회사 내부 문서, 개인 일정 메모 같은 이미지를 낯선 서버에 업로드하는 것은 부담스러울 수밖에 없습니다.

UploadLess는 OCR 처리를 브라우저 안에서 직접 실행합니다. 이미지 파일이 사용자의 기기를 벗어나지 않기 때문에, 업무 자료나 개인 메모처럼 외부에 공개하고 싶지 않은 이미지도 안심하고 처리할 수 있습니다. 서버로 이미지를 보내고 결과를 받아오는 과정이 없다 보니 처리 속도도 대체로 빠른 편입니다.

## 인식 정확도를 높이는 방법

이미지 종류와 상관없이 공통으로 적용되는 기본 원칙은 세 가지입니다.

- **선명한 원본 사용하기**: 흐릿하거나 흔들린 이미지는 어떤 OCR을 쓰더라도 인식률이 떨어집니다.
- **필요한 영역만 잘라서 넣기**: 이미지 전체보다 텍스트가 있는 부분만 크롭하면 OCR이 텍스트 영역에 더 집중할 수 있습니다.
- **결과는 항상 검토하기**: 숫자, 이메일 주소, 고유명사처럼 오류가 치명적인 정보는 붙여넣기 전에 한 번 확인하세요.

## 지원하는 언어와 파일 형식

UploadLess의 이미지 OCR은 다양한 문자 체계를 인식합니다.

- 한국어 (한글 OCR)
- 영어를 포함한 라틴 문자 계열 언어
- 일본어 (히라가나·가타카나·한자)
- 태국어
- 러시아어를 포함한 키릴 문자 계열 언어

파일 형식은 JPG, JPEG, PNG를 지원하며, 클립보드에 복사된 스크린샷도 바로 붙여넣어 처리할 수 있습니다.

## 자주 묻는 질문

### 이미지 텍스트 추출은 무료인가요?
네. 로그인이나 결제 없이 무료로 사용할 수 있으며, 처리 횟수 제한도 없습니다.

### 한 이미지에 여러 언어가 섞여 있어도 되나요?
가능하지만 언어가 많이 섞일수록 일부 문자가 다르게 인식될 수 있습니다. 이런 경우에는 언어별로 영역을 나눠 각각 처리하면 결과가 더 안정적입니다.

### 표나 카드 형태의 이미지도 인식되나요?
텍스트 자체는 추출할 수 있지만, 표의 칸 구조까지 완벽하게 유지되지는 않을 수 있습니다. 표 데이터가 중요하다면 추출 후 줄바꿈과 순서를 확인하는 것이 좋습니다.

### 모바일에서도 사용할 수 있나요?
네. 별도 앱 설치 없이 모바일 브라우저에서 바로 사용할 수 있습니다. 사진첩에 저장된 스크린샷이나 사진을 업로드해 처리할 수 있습니다.

### 어떤 브라우저에서 사용할 수 있나요?
크롬, 사파리, 엣지 등 최신 브라우저에서 사용할 수 있습니다. WebAssembly를 지원하는 브라우저라면 PC와 모바일 모두 별도 설정 없이 작동합니다.
