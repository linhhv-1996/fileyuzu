## 바코드 생성기 사용 방법

이 바코드 생성기는 세 가지 방식을 지원합니다. 상황에 맞는 방식을 선택하면 됩니다.

**수동 입력**은 가장 간단한 방식입니다. 코드를 입력하면 바로 바코드가 만들어집니다. 바코드가 한두 개만 필요하거나, 형식을 테스트해보고 싶을 때 적합합니다.

**파일 업로드**는 여러 바코드를 한 번에 만들 때 사용합니다. CSV 또는 Excel 파일을 준비하고 A열에는 코드(code), B열에는 라벨(label)을 넣어 업로드하면 파일에 있는 모든 코드가 바코드로 생성됩니다. 이미 상품 목록이나 재고 목록을 Excel로 관리하고 있다면 가장 빠른 방법입니다. 파일 준비 방법은 [CSV·Excel로 바코드 일괄 생성하는 방법](/ko/blog/bulk-barcode-generator-csv-excel)에서 자세히 설명합니다.

**순차 번호**는 연속된 번호로 바코드를 만들 때 사용합니다. 시작 번호와 개수만 정하면 `TICKET-0001`부터 `TICKET-0500`까지 같은 코드를 자동으로 생성합니다. 이벤트 티켓, 쿠폰 번호, 자산 번호처럼 새 번호 체계를 만들 때 편리합니다.

## 지원하는 바코드 형식

형식마다 용도가 다릅니다. 어떤 값을 담을지, 어디에서 스캔할지에 따라 선택하면 됩니다.

- **Code 128**: 숫자와 영문을 모두 담을 수 있는 유연한 형식입니다. 내부 SKU, 재고 번호, 자산 번호처럼 직접 만든 코드에는 대부분 Code 128이 가장 무난합니다.
- **QR 코드**: URL, 텍스트 등 긴 정보를 담을 수 있고 스마트폰 카메라로 바로 스캔됩니다. 링크 공유, 안내문, 명함 등에 적합합니다.
- **EAN-13**: 마트나 편의점 상품에서 흔히 보는 13자리 유통 표준 바코드입니다. 한국에서 정식 발급된 코드는 880으로 시작합니다.
- **EAN-8**: EAN-13의 축약형으로, 라벨 공간이 좁은 소형 포장에 사용됩니다.
- **UPC-A**: 북미에서 사용하는 12자리 유통 표준입니다. 미국이나 캐나다 시장에 상품을 판매할 때 필요합니다.

어떤 형식을 골라야 할지 고민된다면 [바코드 형식 선택 가이드](/ko/blog/which-barcode-format-to-choose)를 참고하세요.

## 상품 판매용 바코드는 다릅니다

한 가지 분명히 해둘 점이 있습니다. 이 도구는 바코드 **이미지**를 만들어줍니다. 하지만 마트, 편의점, 대형 유통망에서 사용하는 정식 상품 바코드 **번호**는 이미지 생성과 별개로, GS1 Korea(대한상공회의소 유통물류진흥원)를 통해 발급받아야 합니다.

내부 재고 관리, 자산 관리, 이벤트 티켓처럼 직접 정한 코드를 쓰는 경우라면 이 도구만으로 충분합니다. 반면 정식 유통 채널에 상품을 등록하려면 먼저 코드를 발급받고, 그 코드로 바코드 이미지를 만들어야 합니다. 자세한 구분은 [상품 바코드 만들기 가이드](/ko/blog/how-to-make-product-barcodes-for-selling)에서 설명합니다.

## 업로드 없이 브라우저에서 바로 처리

일반적인 온라인 바코드 도구는 입력한 데이터를 서버로 보내 처리합니다. 이 도구는 다릅니다. 바코드 생성은 전부 사용자의 브라우저 안에서 이루어지며, 입력한 코드나 업로드한 파일이 서버로 전송되지 않습니다.

상품 코드, 재고 목록, 자산 번호는 회사 내부 데이터인 경우가 많습니다. 외부로 보내고 싶지 않은 데이터라면, 처음부터 어디에도 업로드되지 않는 방식이 가장 안전합니다.

## PNG와 SVG로 다운로드

생성한 바코드는 PNG 또는 SVG 이미지로 다운로드할 수 있습니다.

- **PNG**: 문서, 프레젠테이션, 웹페이지에 넣을 때 편합니다.
- **SVG**: 크기를 키워도 선이 깨지지 않아 라벨 인쇄에 유리합니다. 인쇄 품질이 중요하다면 SVG를 권장합니다.

라벨지에 출력하는 전체 과정은 [바코드 라벨 인쇄하는 방법](/ko/blog/how-to-print-barcode-labels)을 참고하세요.

## 자주 묻는 질문

### 바코드 생성기는 무료인가요?

네, 무료입니다. 회원가입이나 프로그램 설치 없이 브라우저에서 바로 사용할 수 있으며, 생성 개수 제한도 없습니다.

### 직접 만든 바코드를 상품 판매에 사용할 수 있나요?

내부 관리용, 재고 라벨용이라면 자유롭게 사용할 수 있습니다. 다만 마트, 편의점 등 정식 유통 채널에서 사용하는 상품 바코드 번호는 GS1 Korea를 통해 발급받아야 합니다. 발급받은 번호로 바코드 이미지를 만드는 것은 이 도구로 가능합니다. 자세한 내용은 [상품 바코드 만들기 가이드](/ko/blog/how-to-make-product-barcodes-for-selling)를 확인하세요.

### 어떤 바코드 형식을 선택해야 하나요?

직접 정한 코드(SKU, 자산 번호 등)라면 Code 128, 링크나 텍스트를 담으려면 QR 코드, 정식 유통 상품이라면 EAN-13이 일반적입니다. 상황별 선택 기준은 [바코드 형식 선택 가이드](/ko/blog/which-barcode-format-to-choose)에서 정리했습니다.

### 여러 개의 바코드를 한 번에 만들 수 있나요?

네. 파일 업로드 모드에서 CSV 또는 Excel 파일을 올리면 파일에 있는 코드 전체가 한 번에 바코드로 생성됩니다. 연속된 번호가 필요하다면 순차 번호 모드를 사용할 수도 있습니다. 방법은 [CSV·Excel 바코드 일괄 생성 가이드](/ko/blog/bulk-barcode-generator-csv-excel)에서 확인하세요.

### 입력한 코드나 업로드한 파일은 어디에 저장되나요?

어디에도 저장되지 않습니다. 모든 처리가 브라우저 안에서 이루어지기 때문에 입력한 데이터가 서버로 전송되지 않으며, 페이지를 닫으면 사라집니다.
